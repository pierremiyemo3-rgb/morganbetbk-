**Sports betting bankroll manager** — FR 🇫🇷 / EN 🇬🇧 / IT 🇮🇹

---

## 🚀 Déploiement sur Vercel (5 minutes)

### Étape 1 — Préparer les fichiers
Dézippe ce dossier sur ton ordinateur.

### Étape 2 — Créer un compte GitHub (si pas déjà fait)
→ https://github.com

### Étape 3 — Mettre le projet sur GitHub
1. Crée un nouveau repository nommé `morganbetbk`
2. Upload tous les fichiers dedans (bouton "uploading an existing file")

### Étape 4 — Déployer sur Vercel
1. Va sur → https://vercel.com
2. Clique "Add New Project"
3. Connecte ton GitHub et sélectionne `morganbetbk`
4. Vercel détecte Vite automatiquement → clique **Deploy**
5. En 2 minutes ton site est en ligne ! 🎉

### Étape 5 — Domaine personnalisé (optionnel)
Dans Vercel → Settings → Domains → ajoute `morganbetbk.com`

## 📱 Installation comme app mobile

Sur iPhone/Android, ouvre le site dans Safari/Chrome puis :
- iPhone : bouton Partager → "Sur l'écran d'accueil"
- Android : menu ⋮ → "Ajouter à l'écran d'accueil"

L'app se lancera comme une vraie application, sans barre de navigateur.
